## سرفصل: Install Django

---

### ۱. منابع آموزشی

**مستندات رسمی Django (انگلیسی):**
- https://www.djangoproject.com/download/

**منابع فارسی:**
- [ساخت پروژه در جنگو از نصب تا استقرار (مبین‌هاست) — شامل محیط مجازی و نصب](https://www.mobinhost.com/mag/create-project-django/#1)

**ابزارهای مورد نیاز:**
- پایتون 3.x — از [python.org](https://www.python.org/downloads/)
- pip — به طور پیش‌فرض همراه پایتون نصب می‌شود
- یک ادیتور کد (VS Code، PyCharm و...)

--- 
### تمرین عملی (تیتر کارها)
- نصب پایتون
- بررسی نسخه پایتون
- ساخت پوشه پروژه
- ایجاد محیط مجازی
- فعال‌سازی محیط مجازی
- نصب Django
- تأیید نصب Django
- ساخت پروژه Django
- اجرای سرور توسعه
- مشاهده صفحه پیش‌فرض در مرورگر

### پروژه کوچک
- **سلام دنیا با Django**
  - ساخت اپلیکیشن
  - افزودن اپ به تنظیمات
  - ساخت ویو
  - تعریف URL
  - تست صفحه در مرورگر
